================================================================
  PLAN THỰC HIỆN MG2 (RACING MINIGAME)
================================================================

NOTE KIẾN TRÚC TRƯỚC KHI LÀM
  - MinigameController KHÔNG nên là 1 file dùng chung duy nhất.
    Nếu dồn hết vào 1 file thì sẽ có if/else theo resultType khắp nơi,
    cực khó maintain và bug chồng bug.
    => DÙNG KIẾN TRÚC BASE + DERIVED:
       BaseMinigameController   (logic chung: timer, networking, start/end, scoreboard)
       MG1Controller            : BaseMinigameController  (logic elimination)
       MG2RacingController      : BaseMinigameController  (logic ranking/racing)

  - FinishLine.cs cần sửa: bỏ HasWinner block để cho nhiều player về đích,
    lưu lại thứ tự finish order

  - PlayerMinigameData.cs cần sửa: thêm FinishRank, HasFinished, FinishTime
    để lưu thứ tự winner cho racing và các mode khác sau này

  - Checkpoint.cs và KillZone.cs: dùng chung cho toàn bộ minigame, KHÔNG sửa

================================================================
  PHASE 0 — REFACTOR KIẾN TRÚC MINIGAME  [QUAN TRỌNG NHẤT]
================================================================

  MỤC TIÊU:
  Biến hệ thống hiện tại từ "MG1-specific"
  thành "Framework dùng chung cho mọi minigame"
  Đây là phase đáng làm nhất trước khi thêm bất kỳ obstacle nào.

  ---------------------------------------------------------------
  0.1  REFACTOR MinigameController
  ---------------------------------------------------------------
  VẤN ĐỀ HIỆN TẠI — controller đang assume:
    - Chỉ có 1 winner
    - Game end ngay khi có winner
    - Scoreboard kiểu Winner/Loser
  => Không phù hợp với: racing, team game, survival, point-based game

  ---------------------------------------------------------------
  0.2  CHUYỂN SANG KIẾN TRÚC GENERIC
  ---------------------------------------------------------------

    SingleWinner   - MG1 (Glass Bridge)

    Team           - Future
    Survival       - Last alive
    Score          - Coin collecting

  ---------------------------------------------------------------
  0.3  THÊM enum MinigameResultType
  ---------------------------------------------------------------
  [ ] Tạo enum:

      public enum MinigameResultType

  [ ] Thêm vào BaseMinigameController:

      - MG2: Ranked

  ---------------------------------------------------------------
  0.4  REFACTOR PlayerMinigameData — thêm các fields mới
  ---------------------------------------------------------------
  [ ] Thêm Networked fields:

  ---------------------------------------------------------------
  0.5  TẠO HỆ THỐNG RANKING CHUNG
  ---------------------------------------------------------------
  THAY VÌ:
      PlayerRef winner;
  DÙNG:

  ---------------------------------------------------------------
  0.6  REFACTOR EndGame Flow
  ---------------------------------------------------------------
  Flow mới:
      Player chạm FinishLine
          ↓
      Add vào finishOrder
          ↓
      Kiểm tra:
        - AllPlayersFinished? → EndGame()
        - Timer hết?          → EndGame()
          ↓
      Build Result Table (CalculateRankings)
          ↓
      Show Scoreboard

================================================================
  PHASE 1 — REFACTOR FLOW KẾT THÚC GAME
================================================================

  ---------------------------------------------------------------
  1.1  SỬA PlayerFinished()
  ---------------------------------------------------------------
  HIỆN TẠI:
      PlayerFinished() → EndGame() ngay lập tức

  SAU KHI SỬA:
  [ ] PlayerFinished(playerRef)
      {
          if (HasFinished) return;
          add to finishOrder;
          assign rank = finishOrder.Count;
          mark HasFinished = true;
          RPC_OnPlayerFinished(playerRef, rank);  // hiện "1st!" "2nd!"...
          if (AllPlayersFinished()) EndGame();
      }

  ---------------------------------------------------------------
  1.2  SỬA OnTimeUp()
  ---------------------------------------------------------------
  [ ] Logic mới khi hết giờ:
      - Player đã finish: giữ rank đã có
      - Player chưa finish: sort theo thứ tự ưu tiên:
          1. checkpointIndex (cao hơn = gần hơn)
          2. distanceProgress
          3. world position (trục X/Z tùy map)

  ---------------------------------------------------------------
  1.3  TẠO hàm CalculateRankings()
  ---------------------------------------------------------------
  [ ] Gom toàn bộ ranking logic vào 1 chỗ.
      Sau này racing / score mode / survival chỉ cần override.

  ---------------------------------------------------------------
  1.4  TẠO virtual methods
  ---------------------------------------------------------------
  [ ] Thêm vào BaseMinigameController:
      protected virtual void CalculateResults()   { }
      protected virtual void OnPlayerFinished()   { }
      protected virtual bool CheckGameEnd()       { return false; }

  ---------------------------------------------------------------
  1.5  KIẾN TRÚC ĐỀ XUẤT  [CỰC KỲ KHUYÊN DÙNG]
  ---------------------------------------------------------------
  Base Class: BaseMinigameController
    - Timer
    - Player registration & spawn
    - Networking (RPC chung)
    - Start / End game flow
    - Scoreboard base

  Derived:
    MG1Controller         : BaseMinigameController  (elimination win condition)
    MG2RacingController   : BaseMinigameController  (ranking win condition)

================================================================
  PHASE 5 — IMPLEMENT OBSTACLE THEO NHÓM  [DONE ✓]
================================================================

  KHÔNG làm C1→C11 random. Làm theo nhóm:

  ---------------------------------------------------------------
  Nhóm 1 — Simple Force Obstacles  [DONE ✓]
  ---------------------------------------------------------------
  C1  SpikeBallGround.cs     - Bóng gai mặt đất
      Cấu trúc: 1 object nằm dưới đất
      Khi player chạm: knockback lên + lùi nhẹ (phương án B)
      - OnTriggerEnter: ApplyExternalForce(up + back)
      - Xoay liên tục: transform.Rotate()

  C5  RotatingSpikeTrap.cs   - Bẫy xoay gai
      Cấu trúc: 2 object (đế + phần gai xoay trục Y)
      - rotationSpeed (độ/giây)
      - transform.Rotate(0, rotationSpeed * Time.deltaTime, 0)
      - Trigger: knockback khi chạm player

  C6  JumpPad.cs             - Bẫy nhảy
      Cấu trúc: 2 object (đế + phần lò xo ẩn/hiện theo Y)
      Khi player chạm: nhảy xa hơn bình thường
      - jumpForce + forwardForce
      - Animate lò xo: nén xuống → bật lên
      - Cooldown ~0.5s tránh spam

  C8  Hammer.cs              - Búa tạ
      Cấu trúc: 1 object búa (+ animation tay tùy chọn)
      Khi player chạm: văng mạnh ra khỏi map
      - hammerForce: 3-5x lớn hơn knockback thường
      - knockDirection: lấy từ hướng của búa
      - Vung theo chu kỳ (swingInterval), có warning trước khi vung

  LÝ DO LÀM NHÓM 1 TRƯỚC: cùng dùng knockback framework, test nhanh.

  ---------------------------------------------------------------
  Nhóm 2 — Moving Obstacles  [DONE ✓]
  ---------------------------------------------------------------
  C2  FloatingObstacle.cs    - Vật lơ lửng lên xuống
      Cấu trúc: 1 object
      - Mathf.Sin(Time.time * speed) * amplitude để di chuyển Y
      - Inspector: floatSpeed, floatAmplitude, startY

  C7  SpikedWheel.cs         - Bánh xe gai
      Cấu trúc: 2 object (khung + bánh xe)
      - Bánh xe di chuyển trục Z kiểu pingpong
      - Xoay trục X: rotX = -(moveSpeed / wheelRadius) * Mathf.Rad2Deg
      - Trigger: knockback mạnh khi chạm player

  C11 RollingSpikeBall.cs    - Bóng gai lăn
      Cấu trúc: Spawn ngẫu nhiên (tương tự C4 nhưng bóng)
      + SpikeBallSpawner.cs
      - rollSpeed, di chuyển trục X (hướng player chạy)
      - Xoay trục Z: rotZ = (rollSpeed / ballRadius) * Mathf.Rad2Deg
      - Destroy khi ra khỏi map

  ---------------------------------------------------------------
  Nhóm 3 — Timed Traps  [DONE ✓]
  ---------------------------------------------------------------
  C3  PopupSpikeTrap.cs      - Bẫy gai bật lên
      Cấu trúc: 2 object (base + gai)
      - Gai bình thường ẩn dưới đất, đến thời gian bật lên
      - activeTime (gai trên) / cooldownTime (gai ẩn)
      - Collider chỉ enable khi gai đang bật lên
      - Warning nhấp nháy ~0.5s trước khi bật

  C10 CrushingPress.cs       - 2 vật ép
      Cấu trúc: 2 object (tường A đứng yên + tường B di chuyển trục Z)
      - openPosition / closePosition
      - crushTime / openTime (lặp)
      - Warning âm thanh/hiệu ứng ~1s trước khi ép
      - Khi player kẹt: teleport checkpoint

  ---------------------------------------------------------------
  Nhóm 4 — Spawner Systems  [DONE ✓]
  ---------------------------------------------------------------
  C4  FallingSpikedLog.cs    - Khúc gỗ gai rơi
      + SpikedLogSpawner.cs
      Spawn ở 3 làn Z (trái/giữa/phải), dùng ở đoạn đường dốc
      - Rơi chậm theo Y (Rigidbody gravity nhỏ hoặc MovePosition)
      - Xoay nhẹ khi rơi
      - Destroy khi chạm đất / ra khỏi map
      - Spawner: spawnInterval, random 1-2 trong 3 làn

  C9  TiltingPlatform.cs     - Vật kiểm tra cân bằng
      Cấu trúc: 1 platform + 2 trigger zone (trái/phải)
      - Đếm players bên trái (leftCount) và bên phải (rightCount)
      - leftCount > rightCount  → nghiêng trái (angle âm)
      - rightCount > leftCount  → nghiêng phải (angle dương)
      - Không có player         → về vị trí nằm ngang (0 độ)
      - Tốc độ nghiêng: tiltSpeed (Quaternion.Lerp)
      - Góc tối đa: maxTiltAngle (~30 độ)
      - Gợi ý: Physics Material friction thấp khi nghiêng nhiều

  CÁC BUG GẦN NHƯ CHẮC CHẮN SẼ GẶP:
  1. Double Finish — player chạm finish 2 lần
     Fix: if (HasFinished) return;

  2. Client desync knockback — client tự apply force
     Fix: chỉ HOST apply, RPC xuống client play FX

  3. Checkpoint race condition — respawn sai checkpoint
     Fix: checkpoint update chỉ trên host

  4. Finish order sai khi 2 player finish cùng tick
     Fix: dùng Runner.Tick hoặc FinishTime để phân định
