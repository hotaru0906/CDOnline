GAME FLOW (confirmed)
---------------------
Lobby -> Cutscene -> [Voting -> Tutorial -> Playing -> Scoreboard -> Board] x N -> Roulette -> Result
N = 5-10 (configurable khi tạo lobby)

INTEGRATION VỚI EXISTING SYSTEM
---------------------------------
GameManager.GameState cần thêm:
  - Cutscene  (intro Timeline)
  - Board     (board phase)

ProceedFromScoreboard() hiện tại đang đi thẳng sang Voting / Roulette
-> Cần đổi thành: Scoreboard -> Board

Cần thêm ProceedFromBoard():
  - Nếu còn round: Board -> Voting
  - Nếu hết round: Board -> Roulette

Turn order trong Board lấy từ minigame rank:
-> GameManager cần [Networked] NetworkArray<int> LastMinigameRanking
-> MinigameController.EndGame() set ranking trước khi gọi EndMinigame()
-> BoardManager đọc ranking này để set thứ tự tung xúc xắc

Network layer: Fusion (Photon Fusion)
-> BoardManager, BoardPlayerToken = NetworkBehaviour
-> BoardNode, BoardDice = MonoBehaviour (không cần sync riêng)
-> Turn state sync qua [Networked] properties + RPC

  ĐÃ IMPLEMENT (BoardNodePath.cs + BoardNode.cs)

  Cách hoạt động:

KNOWN ISSUES / RISKS
================================================================
1. NetworkArray size phải cố định khi declare (Fusion limitation)
   -> LastMinigameRanking size = 4 (max player count)
   -> HeldItems size = 5

2. BoardScene load/unload cần cẩn thận với DontDestroyOnLoad objects
   (CameraManager, GameManager đều là DDOL)
   -> BoardManager KHÔNG dùng DontDestroyOnLoad
   -> BoardManager spawn/despawn theo scene lifecycle

3. Round đầu tiên chưa có ranking từ minigame
   -> Fallback: random order hoặc seat order từ lobby

4. ProceedFromScoreboard() cần biết đây có phải round cuối không
   -> GameManager.CurrentRound >= TotalRounds -> Board -> Roulette
   -> Còn lại -> Board -> Voting

5. TotalRounds hiện là [Networked] int, giá trị mặc định = 3
   -> Cần UI trong Lobby để set 5-10
